# 为什么已有密钥还需要发表开关

稿栈用 connected 函数判断是否允许通过服务端发表。它要求三个条件同时满足，ENABLE_PUBLISH 的值是字符串 true，而且存在微信公众号 App ID 与 AppSecret。只填写密钥不会让发表入口自动可用。

列表接口把这个结果发送给客户端，客户端据此设置发表按钮的状态。真正收到发表请求时，服务端还会重新检查。因此浏览器显示与服务端执行都有对应判断。配置改变后需要部署新版配置，页面也需要重新读取状态。

## 复现

运行 `node --test tests/publication.test.mjs`，查看发布流程测试。它先提供测试 App ID 和 AppSecret，但不启用开关，发表请求应返回 503。然后把 ENABLE_PUBLISH 设为 true，再验证模拟的提交与回执查询流程。

开关只是部署者决定是否启用能力的一处配置。能够发表还取决于微信账号接口权限、网络和稿件状态。界面中的已配置状态只能表示这些服务端配置条件已满足。
