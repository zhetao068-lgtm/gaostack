# 纯文本稿件如何转换成微信图文

稿栈保存的是纯文本正文。调用微信草稿接口时，程序才把正文转换成 HTML。它先按空行分段，把段内的换行转换为换行标签，再用段落标签包住各段。因此编辑时只需区分段落和换行，发布时仍能保留这两个层次。

转换过程中，程序会先把正文中的尖括号和与号转义。例如编辑者输入「温度 < 30」，这个小于号到了 HTML 里会表示为文本。稿件的创作来源也参与转换。选了 AI 生成时，程序会在正文前加入对应说明。选了 AI 辅助时则使用另一条说明。

运行 `node --test tests/publication.test.mjs`，可以查看模拟草稿接口收到的内容。测试输入带尖括号的正文，同时验证生成的 HTML 包含 AI 来源说明和经过转义的正文。测试覆盖本地生成的内容，实际显示效果仍由微信编辑器决定。
