# 一个忙碌标记如何约束界面操作

稿栈通过 guarded 包装保存、导入、发布和查询回执等异步操作。操作开始时，它先设置 busy。如果上一项操作还在执行，新的受包装操作会直接返回。

同一页面里，保存请求未完成就再次点击保存，不会马上发出第二个保存请求。新建稿件与底部页面导航也主动检查 busy。代码把清理放在 finally，所以请求失败之后，界面仍有机会执行下一次操作。

## 复现

打开编辑器，在浏览器开发工具中把网络速度调慢。保存一篇测试稿，连续点击保存，在网络面板里观察请求。随后将网络设为离线并保存，检查错误提示。恢复网络后，再次保存应能发起新的操作。这些步骤可用于验证 busy 在等待与异常路径下的行为。

它只覆盖单个页面内使用该包装或主动检查的操作。其他标签页有自己的页面状态，因此服务端仍通过数据库发布记录控制重复提交。本地自动测试覆盖服务端并行发布路径，未自动执行上述浏览器慢网步骤。
