# 构建脚本怎样把工作台装进一个入口

稿栈的构建脚本读取四个文件，分别是页面、样式、客户端脚本与服务端代码。前三份内容通过 JSON.stringify 转成 JavaScript 字符串常量，随后与服务端代码组合，生成 dist/server/index.js。

服务端把页面、样式和客户端脚本映射到各自的路径。浏览器仍然按 HTML、CSS 和 JavaScript 的常规方式加载它们，部署端则只需要包含构建好的服务端入口。这里没有运行时从个人电脑读取文件的步骤。

## 复现

在仓库根目录运行 `node build.mjs`，随后运行 `node --check dist/server/index.js`。本次执行两条命令均成功，确认脚本能生成可解析的产物。检查脚本还可看到，所有输入位置都通过 import.meta.url 定位，所以构建输入相对于脚本文件，而非调用命令时的任意目录。

构建会把源代码内容写入产物，因此公开源码中的文本同样会进入产物。部署包应从已检查过的源文件构建。应用运行时使用的数据库和密钥通过部署环境提供。
