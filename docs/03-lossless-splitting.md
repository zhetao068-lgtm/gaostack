# 长文拆分如何保留每个字符

编辑者想把长文分成篇幅相近的几篇，读者希望每一篇在自然的地方停下来。稿栈先记录换行和句末标点之后的位置，再从符合长度上限的候选位置中选择离目标篇幅最近的一处。若单段太长而且没有合适的断点，程序会提示调整篇幅或补充段落。

每个片段直接来自原始字符串。关键校验是 `parts.join('') === body`。如果在保存前分别去掉片段首尾的空白，再拼接就会丢失原来的换行。稿栈用去除空白后的结果判断片段是否为空，切片本身保留原样。

预览时返回原稿修订值。另存时若原稿已更新，接口会要求重新预览，避免按过期正文另存。原稿与分篇各自保留。

运行 `node --test tests/publication.test.mjs`，查看 `split preserves all source text`。测试生成带换行的中文文本，验证直接拼接能恢复原文。目标长度按 JavaScript 字符串长度计算，含表情的文本只适合用它估算篇幅。
