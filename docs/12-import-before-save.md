# 导入文件为何先进入编辑器

稿栈导入文件时，会先让使用者选择本地文件。文件大小超过 1.2 MB 会被拒绝。JSON 文件需要表示单篇对象，标题、正文等字段只有在类型为字符串时才会放进对应输入框。正文同时兼容 body 和 content 字段。

普通文本与 Markdown 的第一行用作标题，开头的 Markdown 标题符号会被移除。后续行组成正文。如果文件只有一行，程序会把原始文本作为正文，编辑者仍可在保存前修改。

封面有独立校验。JSON 中的 image 只有符合支持的 Data URL 格式且长度低于限制时，才会放进预览。这里不会把本机文件路径当成上传图片。

## 复现

分别准备两份测试 JSON，一份为单个包含 title 与 content 的对象，另一份为数组。通过导入入口打开，前者会进入编辑器，后者应提示选择单篇稿件。导入完成后检查稿件库，只有点击保存之后才会新增记录。这来自客户端的导入与保存路径，文章没有把手工复现步骤写成已完成的自动测试。
