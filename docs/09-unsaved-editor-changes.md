# 编辑器如何发现未保存的改动

稿栈在打开或成功保存稿件时，记录一份表单快照。快照包含标题、作者、主题、摘要、正文、来源和封面。判断是否修改过时，程序重新读取这些值，将序列化结果与快照比较。

这个判断用于切换稿件等操作。若当前内容有变化，界面会询问是否继续切换。发布按钮也检查未保存状态，要求先保存再提交。这样，读者在预览里看到的内容与服务端准备发表的版本有了明确衔接。

## 复现

在编辑器创建并保存一篇测试稿，改动标题后点击发布，页面会提示先保存。撤销标题改动，使所有字段恢复到刚保存时的值，再次检查时就不会被判为未保存。封面也属于快照的一部分，换图片后同样需要保存。

这份快照存在浏览器内存中，用于比较当前表单。服务端仍会用修订值检查发布请求。编辑器的改动提示与服务端版本检查各自在自己的位置起作用。
