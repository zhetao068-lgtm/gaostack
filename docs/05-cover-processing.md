# 封面上传前，浏览器做了什么

稿栈接收 PNG、JPEG 和 WebP。通过图片选择器上传时，浏览器先检查文件类型和大小，超过 15 MiB 会提示重新选择。解码后，程序按比例把长边缩到最多 1500 像素。较小的图片保留原尺寸。

画布先填白色再绘制图片，因此透明背景导出后会显示为白色。程序依次尝试四档 JPEG 质量，选用第一份 Data URL 长度小于 940,000 的结果。这个长度包含编码和前缀，不能直接当成 JPEG 文件字节数。保存接口另有 950,000 字符的图片字段上限。

想查看效果，可以在稿栈选择一张长边超过 1500 像素、带透明背景的 PNG，再导出稿件 JSON。图片字段会以 `data:image/jpeg;base64,` 开头。将它作为图像打开即可检查尺寸和白色背景。这是从图片选择器导入时的处理路径，直接导入稿件 JSON 有独立校验。
